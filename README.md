# PSL - All Season - Analytics - Dashboard

📌 Project Overview
The PSL Analytics Dashboard is an interactive Business Intelligence project developed using Microsoft Power BI to analyze and visualize Pakistan Super League data across multiple seasons.

The dashboard transforms raw cricket data into meaningful visual insights covering:
- Team performance
- Player performance
- Season-wise trends
- Batting statistics
- Bowling statistics
- Team championship records
- Player nationality distribution
- Venue analysis
- Tournament financial information
- Audience/viewership metrics
The main goal of this project is to demonstrate how data analytics and interactive visualization can be used to convert sports data into clear, decision-oriented insights.
---

🎯 Project Objectives

The key objectives of this project are:
1. Analyze PSL performance across different seasons.
2. Compare team achievements and championship records.
3. Identify top-performing batsmen and bowlers.
4. Analyze season-wise scoring trends.
5. Visualize player nationality distribution.
6. Analyze PSL venues and match locations.
7. Present important tournament KPIs in an interactive dashboard.
8. Build a professional Power BI portfolio project demonstrating practical Data Analytics skills.

💡 Key Insights

Based on the dashboard visualizations, several important insights can be explored:

🏆 1. Team Success

Islamabad United and Lahore Qalandars appear among the leading teams in terms of total PSL titles, with 3 titles each in the dashboard data.

🏏 2. Batting Performance

The season-wise analysis demonstrates how individual batsmen have dominated different PSL seasons, with players such as Babar Azam, Fakhar Zaman, Kamran Akmal, and others appearing among the top scorers.

🎯 3. Bowling Performance

The top wicket-taker visualization highlights the changing bowling leaders throughout different PSL seasons.

📈 4. Scoring Trends

The season-wise trend demonstrates fluctuations in overall runs across PSL seasons, providing a historical view of scoring performance.

🌍 5. International Participation

The nationality visualization demonstrates that PSL includes players from Pakistan as well as international cricketing nations.

💰 6. Financial Growth

The season-wise Diamond, Gold, and Silver category values show changes in PSL's player-category financial structure over time.
